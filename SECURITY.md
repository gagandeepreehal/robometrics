# Security Policy

## Supported Versions

RoboMetrics has not made a stable public release yet. Security fixes are handled on the `main` branch until versioned releases begin.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting if available for the repository, or contact the maintainers through the repository owner account.

Include:

- A description of the issue.
- Steps to reproduce.
- Affected versions or commit hashes.
- Any known workarounds.

Maintainers should acknowledge valid reports within a reasonable timeframe and coordinate a fix before public disclosure.
