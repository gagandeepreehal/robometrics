# Third-Party Dependencies

RoboMetrics depends on the following direct runtime packages:

| Package | Purpose | License |
| --- | --- | --- |
| NumPy | Array operations | BSD-3-Clause |
| SciPy | Spatial distance utilities | BSD-3-Clause |
| pandas | CSV loading and DataFrame export support | BSD-3-Clause |

Development dependencies:

| Package | Purpose | License |
| --- | --- | --- |
| coverage.py | Coverage measurement | Apache-2.0 |
| mypy | Static type checking | MIT |
| pre-commit | Local hook runner | MIT |
| pytest | Test runner | MIT |
| pytest-cov | pytest coverage integration | MIT |
| Ruff | Linting | MIT |

This file lists direct dependencies only. Verify dependency licenses again before publishing a release artifact.
